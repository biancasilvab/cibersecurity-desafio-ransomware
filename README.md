# cibersecurity-desafio-ransomware

## Ferramentas utilizadas:
• Sistema operacional Kali Linux <div>
• Arquivos 'encrypter.py' e 'decrypter.py'

## Utilizando criptografia na prática: 
<div>
• Escrever algo em um arquivo .txt <div>
• No terminal: <div>
• Criptografar o arquivo: python encrypter.py <div>
• Acessar o arquivo gerado: nano teste.txt.ransomware <div>
• Descriptografar o arquivo: pyhon decrypter.py <div>
• Acessar o arquivo gerado: nano teste.txt <div>
